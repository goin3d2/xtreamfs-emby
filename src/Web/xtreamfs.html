    Category changes at the provider

    None seen yet.
    Untick categories to leave them out. A folder name gives a category its own top-level folder, so it can be its own Emby library. Save and refresh applies the changes.

    .strm folder

    xtreamfs writes Movies, TV and any category folders here. Point your Emby libraries at those subfolders. Pick an empty folder: files xtreamfs didn't write are left alone, but this folder is xtreamfs's to manage.

    Folders

    TV libraries treat each folder directly under TV as a show, so with TV subfolders on, add every category folder to the library separately. Usually best left off. Turning either option on or off moves every title once.
    For example 46260,31910=Anime;1234=Kids
    For example 128,129=Anime Movies

    Metadata files

    Locked titles get no artwork from Emby's image downloaders. Leave both off to let Emby fetch everything from TMDB.

    Refresh

    Higher is gentler on the provider, but refreshes take longer.
    Keep the previous library if a refresh would remove more than this share of movies or shows. 0 turns it off.
    Ignore the guard for libraries smaller than this.
    Not needed if real-time monitoring is on for the libraries. The refresh schedule is under Scheduled Tasks (Refresh xtreamfs catalog).
